# scaling_intra_urban_climate

Repository for the paper:

Duran-Sala, M., Hendrick, M. & Manoli, G.  
*Scaling intra-urban climate fluctuations*.  
Nature Cities (2026).  
https://doi.org/10.1038/s44284-026-00441-z

Preprint available at:  
https://arxiv.org/abs/2505.19998

## Structure

- `src/` – Main code modules for data processing, analysis, and plotting
- `datasets/` – Generated CSV datasets used in the analysis
- `requirements.txt` – Python dependencies
- `README.md` – This file

## Installation

Install all required Python packages with:

    pip install -r requirements.txt
